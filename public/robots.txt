# TestPrepPilot — robots.txt
#
# Everything on this site is free to read and free to cite. The explicit
# per-agent blocks below exist because several AI crawlers are blocked by
# default elsewhere on the web (or infer a block from a bare wildcard rule on
# hosts with aggressive defaults), and because a publisher that WANTS to be a
# source for AI answers should say so. Per-agent Allow rules are written out
# rather than implied, so the intent survives any future edit to the wildcard
# block.
#
# AI answer surfaces served by these agents:
#   GPTBot / OAI-SearchBot / ChatGPT-User  → ChatGPT search + training
#   PerplexityBot                          → Perplexity answers
#   ClaudeBot / anthropic-ai / Claude-User → Claude
#   Google-Extended                        → Gemini app & Vertex grounding
#   Applebot-Extended                      → Apple Intelligence summaries
#   Amazonbot, meta-externalagent, YouBot, Diffbot, cohere-ai, Bytespider
#
# A machine-readable map of our best content lives at /llms.txt, and the full
# agent-facing discovery surface is indexed from /.well-known/ai-catalog.json.
#
# Content-Signal is a non-binding, machine-readable statement of preference
# (https://contentsignals.org/). This site's purpose is to be found and cited:
# training corpora, search indexing and real-time AI input (citations / RAG)
# are all deliberately welcome. Flip any one of these to "no" to reserve that
# right — note that Google-Extended, Applebot-Extended, GPTBot and ClaudeBot
# bundle training WITH grounding in a single token, so a blanket no also closes
# the citation channel.
