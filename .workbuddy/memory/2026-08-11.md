## Article-page sidebar（"On this page" TOC）重构
- 截图问题：每篇文章页右侧 TOC 三宗罪——(a) 项太细（17+ 平铺：Quick answer / Overview / Eligibility / The exam / What is tested / "0" / How to register / Rules & renewal / 8 个 depth sections 平铺…）；(b) 长度溢出视口底部；(c) 当中出现裸 "0"。
- "0" 的根因（重要 JSX 陷阱，记一次）：`src/pages/exams/[slug].astro` 旧代码 `(mode === 'researched' || (mode === 'national' && (costs || natTimeline.length))) && (<li>...</li>)`——当 `costs` 是 null/undefined 且 `natTimeline` 是空数组时，`(null || 0)` 返回数字 `0`，`expr && JSX` 把 `0` 当成 JSX 文本渲染出来。所有此类条件现在都用 `!!(...)` 显式强转布尔。
- 设计改：新建共享组件 `src/components/SidebarTOC.astro`，NYT 编辑极简风——
  - "On this page" 黑色细线下 eyebrow
  - 章节式标题 6 个：`01 The basics / 02 What you need / 03 Plan & pay / 04 Career / 05 Preparation / 06 Reference`，编号用 Cormorant Garamond italic
  - 左侧 1px 灰线竖向导轨 + 当前章节 2px 蓝色活动轨（scroll-spy）
  - 子项缩进 + 自身 1px 灰线树状结构
  - 字号比原版小 1px + 行高 1.35，单屏塞下 ~12 项
  - `max-height: calc(100vh - 6rem)` + `overflow-y: auto`，溢出时内嵌滚动（顶部/底部用 mask 渐隐）
  - IntersectionObserver 实时跟踪当前 section，~33% 视口线触发活动项
  - 数据接口：`items: { id, label, sub?, chapterTitle? }[]`；带 chapterTitle 的项同时充当"章节首项"链接（如 Salary → "Career outlook"）
- 两个调用点改用新组件：`src/pages/exams/[slug].astro`（核心，按 mode 拆分四大章）和 `src/components/ExamGuide.astro`（paths 站用，结构更简单）。两处旧 `.sticky-nav` CSS 都已删，仅保留 `.sidebar` 作为 grid slot。
- 8 个 P0 depth sections 被聚成 2 章节簇：salary + pass-rate → "Career"；其余 6 个 → "Preparation"。簇首项名是 umbrella label（Career outlook / Master the material），子项各自直达 anchor。
- Build 通过（5s）；preview server http://127.0.0.1:4321 抓 Security+/ACE/CPA 验证 HTML 结构正确，scroll-spy 脚本 token（IntersectionObserver/scrollIntoView/setActive/toc-root）全部内联到产物里。
- 没碰：aside 外层（保留 `.sidebar` 让 grid 槽不动）、tokens.css（用 CSS 变量）、depth data schema（只重排不改 schema）。
- **跟进修复（sticky 失效）**：首版组件把 sticky 加在 `.sbtoc-nav` 上，但它外层包了 `.sbtoc` div——该 div 高度=内容高度，sticky 没有可滑动的父容器，整个侧栏随页面滚走。修复：删掉外层 div，让 `<nav class="sbtoc">` 直接成为 `aside.sidebar`（网格项，stretch 到文章全高）的子元素；`top` 从 2rem 改 5rem（Header 是 `position:sticky; top:0`，高约 4.5rem，5rem 刚好在它下方）。经验：**Astro 组件里做 sticky 导航，根元素必须是 grid slot 的直接子元素，多包一层 div 就会杀死 sticky**。
- 细节打磨：mask 渐隐只在内容溢出时通过 JS `has-overflow` class 启用，且只淡底部、不淡顶部 eyebrow（首版无条件 top+bottom mask 会把 "On this page" 标题也淡化）。
