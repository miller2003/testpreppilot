## 2. Chunked research pipeline — the important reusable artifact

The previous run died because subagents were each given ~100 exams: the streamed write
truncates around record 50-60, and a rate-limit wiped the whole batch. Fixed by making
the unit of work small and the whole thing resumable.

New tools in `src/data/examCatalog/national-research/`:
- **`makeChunks.mjs`** — splits the 42 `_input/batchNN.json` into **110 chunks of ~29 exams**,
  grouped by certifying body (first-fit-decreasing bin packing) → `_input/chunks/bNN-pM.json`.
- **`mergeChunks.mjs`** — folds `_chunks/*.mjs` + existing `batchNN.mjs` into the 42 batch
  modules `index.mjs` already imports. Re-files each record into the batch its slug belongs to.
  Collapses duplicate-body dossiers (keeps the richer). Emits each dossier into exactly ONE
  batch file. Parks dossiers with no exams in batch01 so research is never lost. Idempotent.
- **`status.mjs`** — progress bar, partially-done chunks, `--next N` to hand out work.
- **`_BRIEF.md`** — the brief every research subagent reads.
- **`RUNBOOK.md`** — resume instructions + failure-mode table.
- **`repairBatch.mjs`** (from earlier) — salvages truncated / mis-quoted batch files.

## 4. Gotchas worth remembering

- **Subagents get these wrong unless told explicitly** (now in `_BRIEF.md` + every prompt):
  exam→program link is the **`body`** string (never `programId`); `examMeta` keys are exactly
  questions/time/pass/fee/format/admin; `examEssentials` is `[label, value]` pairs not an object;
  `roadmap` is strings not objects; one `export default` only.
- `timeline` and `costBreakdown` were missing from ~90 early records → now marked **required**
  in `_BRIEF.md` because they drive a visible page section.
- **Astro build hangs at the end** in this sandbox: `cleanServerOutput` tries to delete 100+
  files in `dist/pages` and trips the bulk-delete guard, which then waits forever. The HTML is
  already fully written by that point — kill the build and remove `dist/pages` from Node.
  (One run hung 1h28m before I noticed.)
- Astro CLI is `node_modules/astro/astro.js`.
