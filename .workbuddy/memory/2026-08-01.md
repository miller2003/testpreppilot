### CONVENTIONS ESTABLISHED
- `states[CODE]` PRESENT = jurisdiction really issues it; ABSENT = it does not. Never use
  exists:false, never delete the page. This is the single mechanism for marking false positives.
- Deep prose lives at TEMPLATE level (written once, reused across that template's states); only
  agency / agencyUrl / fee / note / compactMember vary per state.
- Research schema contract: `src/data/examCatalog/RESEARCH_SCHEMA.md`.
- Astro CLI: `node_modules/astro/astro.js` (NOT dist/cli/astro.js).
- Pagefind CLI: `node_modules/pagefind/lib/runner/bin.cjs`.
